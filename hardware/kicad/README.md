# Carrier PCB (KiCad)

Phase 7. A 2-layer board on the Pi 40-pin header, checked with `kicad-cli sch erc` and
`kicad-cli pcb drc`, with Gerbers, drill, BOM, pick-and-place and STEP exported by `kicad-cli`.
KiCad is not installed on the development laptop yet: install KiCad 9 (or newer) from kicad.org.
