# Carrier PCB (KiCad 10)

A 2-layer board the size of a Raspberry Pi HAT (65 × 56.5 mm) that plugs onto the Pi's 40-pin header
and replaces the breadboard wiring of `docs/wiring.md`. It is fully generated by scripts from one
table, checked by KiCad, and exported ready to order.

```bash
cd hardware/kicad
./build.sh          # about 2.5 minutes; needs KiCad 10 (its own Python and kicad-cli)
```

| File | What it does |
|---|---|
| `carrier.py` | **The netlist table**: every part, value, footprint and the net of each pin. Change the circuit here. |
| `make_schematic.py` | Writes `carrier.kicad_sch`: symbols copied from KiCad's library, a net label on every pin, functional blocks |
| `make_pcb.py` | Writes `carrier.kicad_pcb`: placement table, board outline, routing, GND pour on both layers, silkscreen labels |
| `router.py` | Small A* maze router (KiCad has no autorouter, and Freerouting needs Java) |
| `carrier.kicad_dru` | Extra design rules: lock tracks at least 1.0 mm |
| `build.sh` | Runs everything: ERC, routing, DRC (with schematic parity), exports |
| `output/` | Schematic PDF, ERC/DRC reports, `carrier-gerbers.zip` (Gerbers + drill), BOM, pick-and-place, STEP, renders |

The `.kicad_sch` and `.kicad_pcb` open normally in KiCad. If you edit them by hand, the next
`./build.sh` overwrites them: make the change in `carrier.py` or the placement table instead.

## What is on the board

| Block | Parts | Notes |
|---|---|---|
| Pi header | J1 2×20 female socket on the **bottom** side | Pin 1 = square pad, matches the Pi when the board sits on top |
| DS18B20 | J2 (JST-XH 3), R1 4.7 kΩ to 3.3 V | 1-Wire pull-up |
| DHT22 | J3 (JST-XH 3), R2 10 kΩ | leave R2 out if the DHT22 module has its own pull-up (VERIFY) |
| Reed switch | J4 (JST-XH 2) | uses the Pi's internal pull-up |
| 12 V sense | J9 (screw), R3 10 kΩ / R4 2.7 kΩ divider, C1 100 nF, R5 1 kΩ, D1 BAT54S | 2.55 V at 12 V, 3.19 V at 15 V; BAT54S clamps GPIO 22 between GND and 3.3 V |
| Buzzer | J6, R6 1 kΩ, Q1 BC547, D2 1N4148 | low-side switch, diode across the coil |
| LEDs | J5, R7/R8 330 Ω | LEDs sit on the lid; common GND |
| Lock | J10 (5 V lock adapter in), J11 (solenoid), Q2 AO3400A, R9 100 Ω, R10 10 kΩ, D3 1N4007 | R10 holds the gate low, so the lock is OFF when the Pi is off or booting |
| LCD level shifter | Q3/Q4 BSS138, R11/R12 10 kΩ to 5 V, J7 (JST-XH 4, backpack order GND 5V SDA SCL) | the 3.3 V side uses the Pi's own 1.8 kΩ pull-ups |
| Keypad, spare | J8 (1×8 header), J12 (GPIO 26 + GND) | |

Refs match the breadboard parts list in `docs/wiring.md` where the part is the same.
Differences from the breadboard, and why:

- **Q2 is an AO3400A (SOT-23)** instead of the IRLB8721 (TO-220). It is fully on at 3.3 V gate drive
  (R_DS(on) below 50 mΩ at 2.5 V, datasheet), so at about 1 A it dissipates about 50 mW. The TO-220 laid flat
  would need 21 × 11 mm of board.
- **D1 is a BAT54S** (two Schottky diodes in one package) instead of a single 1N5819: it clamps
  both above 3.3 V and below GND.
- **The BSS138 level shifter is on the board** instead of the separate module (D13).

### Why no PC817 optocoupler on the 12 V sense input

An optocoupler isolates two circuits with different grounds. Here the 12 V adapter's negative
must already be joined to the Pi's GND: the lock and the sense divider need a common ground anyway.
So isolation would gain nothing, and the divider + series resistor + clamp is simpler and protects
the GPIO against the realistic faults (a 15 V unloaded adapter, spikes, reversed or missing
ground on the sense wire). A PC817 would be the right choice only if the sensed supply had its own
ground, for example a separate battery system. It would then work like this: 12 V → resistor →
PC817 LED, and the photo-transistor pulls GPIO 22 low against a pull-up, so the logic is inverted.
Nothing on this board ever connects to 230 V.

### Track widths

| Nets | Width | Why |
|---|---|---|
| `+5V_LOCK`, `LOCK_N`, lock return (J10 GND ↔ Q2) | 1.0 mm | solenoid current about 1 A (VERIFY). IPC-2221 for 1 oz outer copper and a 10 °C rise needs 0.30 mm; 1.0 mm leaves margin for the pull-in surge |
| `+5V` | 0.4 mm | buzzer, LCD backlight (well under 0.5 A) |
| `+3V3`, `GND` tracks | 0.3 mm | plus a GND pour on both layers |
| signals | 0.25 mm | |

The Peltier's 12 V / ~5 A never comes onto this board: J9 carries only the divider's ~1 mA.

## Ordering

Upload `output/carrier-gerbers.zip` to any 2-layer PCB service (for example JLCPCB, PCBWay):
1.6 mm FR-4, 1 oz copper, HASL or ENIG, any colour. The design uses 0.25 mm tracks, 0.2 mm
clearance and 0.3 mm via drills, which every standard process allows. `output/carrier-bom.csv`
lists the parts and `output/carrier-pos.csv` the SMD positions (origin: bottom-left corner).

Shipping from abroad will not arrive before the 2 Dec demo (decisions.md), so the demo uses the
breadboard/protoboard build and this design is shown in the report.

## Before ordering: VERIFY

- [ ] Pi header position and pin 1 (from the HAT drawing: rows 2.23 / 4.77 mm from the top edge,
      pin 1 at x = 8.37 mm): print `output/carrier-top.png` at 1:1 or check the PDF against the Pi
- [ ] Standoff height between Pi and board: about 11 mm for an 8.5 mm female socket (measure the socket)
- [ ] BC547 pin order C-B-E (the footprint uses this order)
- [x] Keypad ribbon order R1–R4, C1–C4 matches J8 pins 1–8 (seller's diagram)
- [ ] LCD backpack pull-ups: if it already has 5 V pull-ups, leave out R11/R12
- [ ] DHT22 module pull-up: if it has one, leave out R2
- [ ] Solenoid current (measure): if it is above 1.5 A, ask for wider tracks
